Example procedures

Show the steps and the guardrails.

Procedure examples make the demo concrete: what the agent checks, what the customer confirms, and when work must stop or move to a person.

Auto Assist procedure · Returns & Exchanges

Initiate a return

Validate eligibility, explain the available choices, and create the return only after the customer confirms.

Example path
  1. Verify the customer and resolve the correct order and item.
  2. Check delivery state, return window, item rules, and any existing return or refund.
  3. Explain eligible methods, fees, timing, and approved alternatives.
  4. Confirm the item, quantity, and method before any write action.
  5. Create the return, verify the RMA result, and share next steps.
Branches to include in the demo
  • Not delivered: stop the return and route to delivery support.
  • Already refunded or returned: retrieve the existing status; do not duplicate.
  • Outside policy or system unavailable: explain what is known and create a human follow-up.
Demo prompt: “Can I return the jacket from order 10482? It arrived last week.” Use a fictional order and the retailer’s sample policy.
Auto Assist procedure · Payments & Refunds

Check refund status

Give a grounded update without promising a bank posting date the system cannot verify.

Example path
  1. Authenticate and find the relevant order, item, and refund event.
  2. Check whether a refund is pending, submitted, completed, failed, or not found.
  3. Explain the source status, amount, destination, and expected timing when available.
  4. If status is missing or delayed, capture the case and route follow-up to the right team.
Branches to include in the demo
  • Multiple refunds: clarify which item or transaction.
  • Refund not initiated: explain the next approved step; do not claim it was sent.
  • Payment provider timing unknown: state the limit and offer follow-up.
Demo prompt: “I returned one item from my order. Has the $68 refund been sent?”

These are example configurations. Map them to supported procedure formats, actions, retailer policy, and approved human-review paths.

Custom agent examples

Give each agent a clear job.

Use a bounded role, a useful data context, and an explicit handoff. In a demo, show how the agent behaves when a key fact is missing.

✦
Shopping Assistance

Product recommendations

Helps a shopper choose a product or find an alternative.

Trigger: “Can you help me find a carry-on for a weeklong trip?”
  • Ask about use, budget, and must-have attributes.
  • Search catalog and check current price and location availability.
  • Explain a short list and tradeoffs; keep purchase actions customer-led.
⌁
Fulfillment & Delivery

Delivery and backorder support

Explains shipment status and coordinates the next supported step.

Trigger: “One item shipped, but the other still says backordered.”
  • Separate shipped, delivered, and backordered lines.
  • Use carrier and inventory facts with source freshness.
  • Offer approved options or create a follow-up; never invent an ETA.
♡
Loyalty Support

Loyalty and rewards

Resolves membership and points questions using verified account data.

Trigger: “My points from last weekend’s purchase are missing.”
  • Authenticate and match the loyalty account.
  • Check tier, balance, reward history, and program rules.
  • Request review for adjustments outside the agent’s authority.
